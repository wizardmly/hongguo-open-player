# 播放器交互设计

本文记录现行纯 NSH 原生播放器的交互与快捷键设计；实际实现以 [App.tsx](../App.tsx)、[TheaterView.tsx](../src/pages/TheaterView.tsx) 与 [DESIGN.md](../DESIGN.md) 为准。

## 全局与剧场快捷键策略

在纯 NSH 版本中，快捷键通过 `keymap.bind(..., { when: "notEditing" })` 与焦点状态隔离机制绑定，兼顾观影流畅性与表单输入保护：

- **全局快捷键**（[App.tsx](../App.tsx)）：
  - `Mod+K`：聚焦顶部搜索框
  - `Shift+/`：打开快捷键说明弹窗（`{ when: "notEditing" }`）
- **剧场快捷键**（[TheaterView.tsx](../src/pages/TheaterView.tsx)，均受 `{ when: "notEditing" }` 与 `!props.hasModalOpen` 约束）：
  - `空格` / `K`：播放 / 暂停
  - `↑` / `PageUp`：上一集
  - `↓` / `PageDown`：下一集
  - `←` / `→`：快退 / 快进 5 秒
  - `M`：静音切换（支持鼠标滚轮以 5% 步进微调音量）
  - `D`：开启 / 关闭弹幕
  - `S`：展开 / 收起选集侧边栏
  - `F`（或双击播放画面）：切换全屏 / 普通窗口
  - `Escape`：存在打开弹窗时不触发剧场退出；全屏状态下先退出全屏（`win.setMode("normal")`），非全屏状态下退出剧场返回目录

## 维护与评审约束

- **输入与弹窗隔离**：借助 NSH 原生 `when: "notEditing"` 上下文及 `props.hasModalOpen` 判断，文本输入过程中及弹窗打开期间不会误触发播放、切集或退出剧场快捷键。
- **全屏安全区与工具栏自动隐藏**：全屏下顶部/底部渐变工具栏会随指针空闲自动隐藏，且弹幕层与 OSD 提示自动留出安全边距以免遮挡顶栏状态或人物主体。
- **验证要求**：调整焦点或快捷键绑定后，应确认 `App.test.tsx` 与实机 `verify-windows.ps1` 中的播放控制、搜索输入与弹窗关闭逻辑行为正常。
