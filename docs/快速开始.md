# 🚀 快速开始指南 (Quick Start Guide)

本指南介绍如何运行、开发调试及构建纯 NSH 原生架构的 **红果开源播放器 (Hongguo Open Player `v2.0+`)**。

---

## 方式 1：直接运行免安装便携版（推荐）

前往 [GitHub Releases](https://github.com/wizardmly/hongguo-open-player/releases) 下载 `红果开源播放器.zip`，解压后直接运行：

### 🪟 Windows 平台 (x64)
* 解压压缩包后，双击运行 **`红果开源播放器.exe`** 即可启动原生客户端（**请保持同目录的 `nsh-player.exe` 与 `nsh/` 运行时目录完整**，无需安装 Node.js 或任何桌面运行时）。

---

## 方式 2：本地运行与开发调试（纯 NSH）

1. 安装 [NSH CLI](https://nsh.dev/docs/installation) 并克隆仓库：

```powershell
git clone https://github.com/wizardmly/hongguo-open-player.git
cd hongguo-open-player
```

2. 准备 Windows 本地播放依赖：
   - 执行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/prepare-playback-signer.ps1` 自动下载并校验 SHA256 生成 `build/playback-signer/win32-x64`；
   - 在 `build/media-ffmpeg/x64/ffmpeg.exe` 放置支持 HEVC 与 `-f data` 合并的完整 FFmpeg；
   - 通过 `scripts/build-bytevc2.sh` 构建或放置 ByteVC2 解码器 `build/bytevc2/x64/ffmpeg.exe`。
3. 启动热更新原生桌面窗口：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/dev.ps1 -NshCommand nsh
```

> macOS / Linux / Web 开发运行：安装对应平台目标依赖后在根目录执行 `nsh run App.tsx --target macos`、`--target linux` 或 `--target web`。

---

## 方式 3：构建免安装便携包

```powershell
# Windows 便携包与 ZIP 压缩包（默认输出至 dist/windows-v2.0.0）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-windows.ps1 -NshCommand nsh -OutputDir dist/windows-v2.0.2

# 其他目标平台（输出至 .nsh/out/）
nsh package App.tsx --target macos
nsh package App.tsx --target web
```

---

## 自动化检查与测试

```powershell
# 1. NSH 静态类型检查
nsh check

# 2. 离线密码学 / MP4 CENC 解密 / 协议签名单元测试
nsh test Hongguo.test.ts

# 3. 离线领域模型、预加载缓存队列与无头 UI 回归测试
nsh test App.test.tsx

# 4. Windows 实网端到端测试与切集零黑屏像素校验
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify-windows.ps1 -NshCommand nsh
```

客户端配置、观影历史、收藏与 `media-cache` 磁盘缓存均保存于 NSH 应用数据目录（Windows 默认为 `%APPDATA%\dev.openplayer.hongguo.nsh`）；端到端测试产物位于 `.nsh/test/`，不影响个人观看记录。
